模型条件与原理

总反应：2 H+(aq) + 2 Cl−(aq) → H2(g) + Cl2(g)。本页按指定的析氢、析氯路径作准静态教学模拟；Pt 不消耗。取 25 °C、H+ 和 Cl− 活度为 1，压力参照外界大气压，Eb,max 取约 1.36 V。

少量产物使电极逐渐具有氢电极和氯电极的性质，形成反电动势。界面气体的有效分压越高，反电动势越大；当持续气泡析出时，本模型将其封顶在 Eb,max。低电压区的界面电压还包含双电层极化的贡献。

Eb = E° + (RT / 2F) ln[(pH₂ / p°)(pCl₂ / p°) / (aH⁺² aCl⁻²)]

参考曲线由微电流区、平滑过渡区（图中 2–3）和线性区构成；“2–3”是曲线上的阶段标记，并非 2–3 V。线性区满足 I = (E − E分解) / R，直线延长至 I = 0 得到 E分解。采到至少 3 个线性区数据点后，用最小二乘法拟合其截距。

默认忽略额外超电势，使 E分解 ≈ Eb,max。打开对比后，η总 是线性区近似的等效值，E分解 ≈ Eb,max + η总；实际超电势会随电流、电极表面和体系条件变化，外推值也依赖拟合区间。

中性盐视为不放电的支持电解质，仅改变电导，不改变本页固定的活度与反应路径。相对含量 s 从 0 到 1 时，取 R = 120 / (1 + 4s) Ω。这是用于对比斜率的示意关系，数值并非具体实验的标定结果。

本模型不计算耗尽、析氧竞争、氯气溶解或气体混合反应。气泡逸出采用 p ≈ patm 的教材近似，省略液柱压力、表面张力及成核过饱和；动画中的有效分压和粒子数不是可直接观测的实测数据。降压会直接回到相应准静态状态，不模拟迟滞。
